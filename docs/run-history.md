## 已定位的环境问题（非用例原因）

| 问题 | 表现 | 修复 |
|---|---|---|
| 代理端口写死 | 原按 7897 配置，实际代理软件在 12450 | Runner 改为跟随 Windows 系统代理，不再写死端口 |
| 双重代理 | 同时设置 `HTTPS_PROXY` 环境变量 + 系统代理，SSL 握手失败 | 清空代理环境变量，只走系统代理 |
| **代理掐断长连接** | `broker.actions.githubusercontent.com` 每 100s 超时，任务在 Set up job 阶段失败 | 无法通过配置解决，需换稳定代理；已暂停定时避免无效红叉 |
| SUT 常驻占内存 | Docker/WSL 常开，机器发烫 | 改为 CI 任务内自动拉起、跑完自动关闭 |

## 运行窗口

为降低资源占用与发热，环境只在测试窗口内运行：

| 时间 | 动作 |
|---|---|
| 13:50 | 计划任务 `SpreeStackStart`：启动 Docker → Spree → 等待 3000 端口 |
| 14:10 | GitHub Actions 定时触发（全量 60 条） |
| 15:20 | 计划任务 `SpreeStackStop`：停止容器并关闭 WSL 虚拟机 |

其余时间 Runner 常驻（内存约 100 MB），Docker 与 Spree 关闭。
